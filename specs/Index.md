# Project specification files index

This file provides an entrypoint for the project's specification, listing all
relevant specification files and providing links to them.

## Model

**File:** [Model.md]

Defines the credit score model that is the main deliverable of this project. It 
states the model's target, data splitting proportions, feature engineering, 
cross-validation strategies and algorithms used.

## Data input-output (IO)

**File:** [DataIO.md]

Defines components related to data IO for the project, such as fetching data
from the OpenML database, checking its integrity and saving the data to disk.
